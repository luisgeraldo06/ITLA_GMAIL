9. Atributos HTML

Los atributos agregan propiedades y configuraciones a los elementos HTML.

id

Identifica de manera única un elemento dentro del documento.

class

Permite agrupar elementos para aplicar estilos o seleccionarlos desde JavaScript.

title

Coloca el cursor sobre este texto para ver información adicional en algunos navegadores.

contenteditable

Puedes hacer clic aquí y modificar este texto.

hidden

Este contenido está oculto.

dir

Este texto se muestra de derecha a izquierda.

lang

This paragraph is written in English.

spellcheck

draggable

Este elemento puede ser arrastrable. Para implementar un comportamiento completo de arrastrar y soltar se necesita JavaScript.

11. Estructura básica de un proyecto HTML

Un proyecto web puede organizarse utilizando archivos independientes para cada tecnología. 

mi-proyecto/
│
├── index.html
│
├── css/
│   └── estilos.css
│
├── js/
│   └── app.js
│
├── images/
│   └── logo.png
│
└── documents/
    └── manual.pdf

HTML estructura el contenido. CSS controla la presentación. JavaScript agrega comportamiento e interactividad.
